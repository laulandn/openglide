Attempts to build for classic MacOS 7/8/9 with Retro68...

This is really a fork, and should be one, but while I'm working on it, it is just a separate repo.

This requires SDL1, I've added an attempt to use SDL2 in progress...

This has been tested and works with Mesa.
This has been tested and crashes with TinyGL.

In theory this could be a drop in replacement...but only for compile time.

This is a static only link library version.
This can NOT be used to replace the real Glide.
